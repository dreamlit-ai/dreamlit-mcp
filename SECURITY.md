# Security

If you believe you have found a security issue in Dreamlit MCP, email `support@dreamlit.ai` with the subject line `Security: Dreamlit MCP`.

Please include:

- A short description of the issue.
- Steps to reproduce.
- The affected MCP client, if relevant.
- Any request IDs, timestamps, or screenshots that help us investigate.

Do not include access tokens, personal access tokens, database credentials, or other secrets in the report.
